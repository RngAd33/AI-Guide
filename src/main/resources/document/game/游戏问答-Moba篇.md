3.1 核心机制
补刀 (Last Hit)：正补 (经济)、反补 (DOTA2特有，阻止对方经济)。
视野 (Ward)：
真眼/控制守卫：排眼与反排博弈。
草丛/高低坡：伏击与地形优势 (DOTA2上坡有闪避)。
野区资源：小龙/元素龙 (增益Buff)，大龙/巴龙 (兵线强化)，Roshan (不朽盾)。
3.2 定位与职责
上单 (Top)：半肉战士/坦克，承担伤害，边带牵制。
打野 (Jungle)：Gank (游走抓人)，反蹲，控资源 (龙/先锋)。
中单 (Mid)：高爆发法师/刺客，等级领先，游走支援。
ADC (Bot)：远程持续输出，极度依赖保护，后期核心。
辅助 (Support)：硬辅 (开团/承伤) vs 软辅 (保护/治疗)。
DOTA2 1-5号位：资源分配体系，1号位 (大核刷钱)，5号位 (纯辅助买眼)。
3.3 战斗与操作
伤害计算：护甲/魔抗减伤公式，穿透与削减。
控制链 (CC)：晕眩 (强控)、沉默、缴械、禁锢、压制。
关键操作：取消后摇 (提升DPS)，走A (Attack Move)，风筝 (Kite)。
3.4 游戏差异化策略
英雄联盟：符文系统，召唤师技能 (闪现/传送)，龙魂机制。新手目标：10分钟80刀。
DOTA2：反补，信使，买活，TP卷轴。新手避坑：慎玩影魔。
王者荣耀：无装备 (天赋树)，共享经验，快节奏。操作：三指操作，头像锁定。
风暴英雄：无补刀，无装备，纯团队机制驱动，地图任务优先。
