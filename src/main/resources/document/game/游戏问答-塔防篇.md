2.1 核心循环
资源 (Economy)：击杀奖励 > 利息/自然回复。核心是经济转化率。
阻挡 (Block)：近战单位拦截敌人机制。盾侧输出是通用战术（重装挡怪，远程侧击）。
路径 (Pathing)：固定路径 vs 迷宫建造 (绕路聚怪)。
2.2 单位分类与克制
基石 (Core)：高生存/稳定输出，可单守一路（如明日方舟棘刺）。
速狙 (Rapid)：低费高攻速，前期核心，后期转对空。
群攻 (AoE)：拐角摆放最大化覆盖；克制大量低血怪。
控制 (CC)：减速/眩晕/击退，为输出争取时间。
伤害公式：
物理：max(攻-防, 攻×5%) (抛光线)。
法术：攻 × (1-法抗%)。
2.3 通用策略框架
开局 (1-5波)：低成本防守，建立产费单位。
中期 (6-15波)：升级核心塔，阵线前压。
后期 (Boss)：爆发对齐Boss时间，设置补漏防线。
地形利用：黄金位 (拐角/交汇点)，聚怪 (控制重叠)。
2.4 游戏特化策略
明日方舟：干员再部署CD，费用自然回复。新手必练：挡二先锋 (产费) + 快狙 + 群奶 + 群法。
Kingdom Rush：兵营是核心 (争取时间)，英雄需微操切后排。
Bloons TD 6：农场滚雪球，迷彩需特定塔/技能处理。
植物大战僵尸：垫材法 (挡伤害)，节奏控丑 (防自爆)。
